# Portfolio redesign — design canvas

Working files for the design canvas published at
https://claude.ai/code/artifact/97ea42e4-d086-4f0e-8938-aed853dc279c

Each `.dc.html` is one artboard; `canvas.json` lays them out.
Edit these files and re-seed to update the canvas — never edit
`kushal-amin-portfolio.html` directly, it is generated output.

| File | What it is |
|---|---|
| `Main.dc.html` | Home page, desktop (1440) |
| `Work.dc.html` | Full work index, 14 projects grouped by discipline |
| `Case.dc.html` | Case study — the LLM-as-judge evaluation pipeline |
| `Mobile.dc.html` | Home page at phone width (390) |
| `DirectionB.dc.html` | Alternate direction, low-fi: dark telemetry |
| `DirectionC.dc.html` | Alternate direction, low-fi: heavy display |

## Design system

- Paper `#FBF9F5` · panel `#F2EFE7` · ink `#1A1815` · rule `#DED8CC`
- Accent `#B23D22` (a canvas tweak; secondary status green `#4F6F52`)
- Instrument Serif (display) · IBM Plex Sans (body) · IBM Plex Mono (data)
