AND THEN, THE LAST TWO YEARS

Where AI earns its place

Not demos. Three places where I put a model on work a person was doing by hand — and one where I deliberately did not.

01

It writes the outreach now

A salesperson used to write every follow-up from scratch — the call script, the email, the text. It drafts them now from what the dealership already knows about that customer, in over a hundred languages. It reached every customer in January 2026.

I built most of the service behind it. The parts I would actually point at are not the model call. They are the rules that keep it away from claims a manufacturer’s lawyers would object to, and the step that strips the customer’s vehicle number out before anything reaches the model at all — pinned by a test named after exactly that, so nobody removes it by accident later.

02

It writes the day’s list

Three agents in a chain: one works out who this customer is and what situation they are in, one writes the suggestion, and a third scores it out of ten. Under seven and it does not ship.

QA can add their own scoring rules without waiting on me to change any code — the difference between a quality bar and a bottleneck.

MULTI-AGENT LLM-AS-JUDGE
03

Ask the warehouse in English

Someone non-technical asks a question in plain words and gets a chart back, instead of queueing for an analyst.

The interesting part is the safety. What you cannot trust is the query the model wrote, not the sentence the person typed — so that is what gets checked, word by word, before anything runs. Plus a cost estimate first, because a model writing its own queries is a spending risk.

PYTHON BIGQUERY TOOL CALLING
04

Knowing when not to

Upgrading 2,455 files to a new version of React. I wrote an eleven-thousand-line tool that makes the edits by properly understanding the code — no model anywhere near it.

This problem has one right answer, and a model would occasionally get it wrong in a way nobody notices until production. Same instinct to automate. Different tool.
